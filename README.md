# Fireworks_game
Dynamic Fireworks Generator

Overview

This is a simple, dynamic fireworks simulation built entirely with HTML and JavaScript's Canvas API. It creates a beautiful, interactive night sky where users can launch colorful rockets with a simple click or tap.

The entire application is contained within a single index.html file, making it extremely easy to host and share.

✨ Key Features

Interactive Launch: Click or tap anywhere on the screen to launch a new firework rocket from the bottom center.

Realistic Physics: The simulation includes basic velocity, friction, and gravity to give the rockets and their sparks a natural falling and fading effect.

Responsive Design: The canvas automatically resizes to fit any device (mobile, tablet, desktop).

Custom Colors: Features a vibrant, randomized color palette for diverse explosions.

🚀 How to Play

Open the Application: Open the index.html file in any modern web browser.

Launch a Firework: Click or tap anywhere on the dark canvas. The rocket will launch from the bottom center and explode when it reaches the target location.

Enjoy the Show: Keep clicking to fill the night sky with light and color!

⚙️ Setup and Deployment

Since this project is a single, self-contained HTML file, setup is minimal.

Running Locally

Download: Clone this repository or download the index.html file.

Open: Double-click the index.html file. It will open directly in your web browser.

Static Hosting (e.g., GitHub Pages)

This project is perfectly suited for static hosting platforms as it requires no backend server, databases, or API keys.

Create a Repository: Push the index.html file to a new GitHub repository.

Enable GitHub Pages: Go to your repository settings, navigate to the Pages section, and select the main branch (or whichever branch you used) as the source.

Deploy: GitHub will automatically build and deploy your site, which will be accessible via a URL like https://[your-username].github.io/[repository-name].

💻 Technology Used

HTML5: Structure and Canvas element.

CSS3: Basic styling for the dark background and control panel.

JavaScript: Core logic for the animation loop, physics calculations, and object-oriented programming (using the Firework and Particle classes).

Canvas API (2D): Used for all rendering and visual effects.
